    ✅ 흡수 최적화 조합

    ⚠ 흡수 저해 조합

    체중 기반 철분 계산 로직

    function calculateIronNeeds(ageMonths, weightKg) {
  let dailyIron = (ageMonths < 7) ? 0.27 : (ageMonths <= 12) ? 11 : 7;
  dailyIron = Math.max(dailyIron, weightKg * 1.0);  // 체중 보정
  const oneMealIron = (dailyIron * 0.45) / 3;        // 이유식 1끼 ≈ 45%, 3끼 분할
  return { dailyIron, oneMealIron };
}
    1. 기본 권장 (한국영양학회 2020): 0~6M 0.27mg · 7~12M 11mg · 1~3세 7mg/일
    2. 체중 보정: max(기본권장, 체중kg × 1.0)
    3. 1끼 목표: (일일권장 × 45%) ÷ 3 — 이유식이 하루 철분의 약 45%를 담당한다고 가정
    4. 흡수 추정: 헴철 25%, 비헴철 5%, 비타민C 동반 시 15%, 우유/칼슘 동반 시 50% 감소
    5. 영양 DB: 식약처 국가표준식품성분표 제10차 (100g 기준, 25종)
    6. 성장 백분위: P15 미만 시 영양사·소아과 상담 권장 (성장 탭)
