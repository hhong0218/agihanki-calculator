성장도표 백분위(P) 해석 가이드

P3~15

저체중 경계. 섭취량·성장 모니터링, 소아과 상담 권장.

P15~85

정상 범위. 월령별 권장량 기준 식단 구성.

P85~97

과체중 경계. 과다 열량 주의, 균형 식단 유지.

    ✅ 흡수 최적화 조합

    ⚠ 흡수 저해 조합

    철분 1끼 목표 계산 방식 (투명 공개)

    function calculateIronNeeds(ageMonths, mealsPerDay) {
  // 2025 한국인 영양소 섭취기준: 0~5개월 0.3(충분) / 6~11개월 6(권장) / 1~2세 6(권장) mg
  const dailyIron = (ageMonths < 6) ? 0.3 : 6;
  // 45% = 이유식으로 충당한다고 보는 본 계산기의 자체 가정 (공식 기준 아님)
  const oneMealIron = (dailyIron * 0.45) / mealsPerDay;  // 6M·1끼 / 7~11M·2끼 / 12M+·3끼
  return { dailyIron, oneMealIron };
}
    1. 일일 권장 (2025 한국인 영양소 섭취기준, 보건복지부·한국영양학회): 0~5개월 0.3mg(충분섭취량) · 6~11개월 6mg · 1~2세 6mg(권장섭취량). 참고: 미국 NIH 기준(7~12개월 11mg)은 흡수율 가정이 달라 수치가 다릅니다.
    2. 1끼 목표: (일일 권장 × 45%) ÷ 월령별 끼 수 — 6M 1끼 · 7~11M 2끼 · 12M+ 3끼. 45%는 자체 가정값
    3. 흡수 추정: 헴철 약 25%, 비헴철 약 5%, 비타민C 동반 시 약 15%, 우유/칼슘 동반 시 50% 감소 — 일반 영양학 문헌의 통용 추정치
    4. 영양 DB: 농촌진흥청 국립농업과학원 국가표준식품성분표(제10개정) 기반 대표치 (100g 기준, 25종)
    5. 성장 백분위: P15 미만 시 영양사·소아과 상담 권장 (성장 탭)

    자주 묻는 질문 (FAQ)

    YMYL 건강 정보 — 아래 내용은 교육 목적이며 의료 상담을 대체하지 않습니다.

    이유식 1끼에 철분은 얼마나 필요한가요?+
    2025 한국인 영양소 섭취기준(보건복지부·한국영양학회)의 일일 권장섭취량은 6~11개월 6mg, 1~2세 6mg입니다(0~5개월은 충분섭취량 0.3mg). 본 계산기의 이유식 1끼 목표는 (일일 권장 × 45%) ÷ 월령별 끼 수(6개월 1끼·7~11개월 2끼·12개월+ 3끼)로 계산하며, 45%는 이유식으로 충당한다고 보는 자체 가정입니다. 흡수율을 고려해 헴철·비타민C 식품을 함께 구성하세요.
    3인분 레시피를 1끼로 줄이려면?+
    원래 인분 3, 목표 인분 1로 설정하면 재료·영양소가 자동으로 1/3 계산됩니다.
    시금치만으로 철분이 충분한가요?+
    시금치는 비헴철이라 흡수율이 3~8%에 불과합니다. 소고기·달걀노른자 등 헴철과 비타민C 과일을 함께 제공하세요.
    우유와 이유식을 같이 먹여도 되나요?+
    칼슘·우유 단백이 철분 흡수를 저해합니다. 철분 식품 섭취 후 1~2시간 간격을 두는 것이 좋습니다.
    성장 백분위수는 어떻게 해석하나요?+
    P50은 같은 월령 평균, P3~P15는 저체중, P85~P97은 과체중 범위로 참고합니다. 정확한 판정은 소아과 성장검진이 필요합니다.
    DB에 없는 재료는 어떻게 하나요?+
    재료 행의 "직접입력" 버튼으로 영양값을 수동 입력할 수 있습니다. 농촌진흥청 농식품올바로(국가표준식품성분표)를 참고하세요.
    소분 계산기에서 300ml와 300g/끼는 같은가요?+
    아닙니다. 총량 300ml를 5끼로 나누면 1끼 약 60ml(≈62g)입니다. 300g/끼는 나눌 끼 수가 1일 때만 나오며, 전량을 한 끼로 먹는 경우입니다. 큐브는 ml 기준, 영양 계산은 g 기준으로 각각 표시합니다.
